## 算法竞赛阶段性总结

#### STL相关内容
1. 统一使用size()方法获取容器元素个数
2. 统一使用empty()方法判断容器是否为空
3. clear的行为是移除容器中的所有元素，
   除了array,stack,queue,priority_queue均可使用clear
4. Stack相关内容
   1. stack的初始化
   ```cpp
   stack<int> stk;//创建一个空栈
   //栈 不允许初始化 但允许 从已有的栈进行拷贝构造
   stack<int> stk2(stk);
   stack<int> stk3 = stk2;
   ```
   2. 入栈:push(); 出栈:pop(); 取出栈顶元素(取出元素 但不会被pop()掉):top();
   3. 清空栈:stack中不能遍历
   ```cpp
   while(!stack.empty()) stack.pop();//时间复杂度O(n)
   stack = {};//时间复杂度O(1)
   ```
5. queue相关内容
   1. queue的初始化与stack相同
   2. 入队:push(); 出队:pop(); 取出队首元素:front(); 取出队尾元素:back();
6. map相关内容
   1. map<T_ket,T_value> mp;
   当使用自己定义的结构体作为key时，一定要重载小于号
   ```cpp
   struct Node{
      int x,y;
      //map内部需要比较，如果不重载小于号会报错
      bool operator < (const Node &u)const{
         return x==u.x?y<u.y:x<u.x;
      }
   };
   map<Node,int> mp_Node_int;
   ```
   注意：在map的键值对<key,value>中,一个key唯一对应一个value,不同的key可能对应相同的value。
   2. map的基本操作
      1. insert({key,value});时间复杂度O(logn);
      2. erase(key) 删除map中指定的键值对;时间复杂度O(logn);
      3. find(key) 查找map中指定键对应的键值对的迭代器;时间复杂度O(logn);
      4. operator[key] 查找map中指定键对应的值;时间复杂度O(logn);
      5. count(key) 查找map中键的数量，由于键唯一，故只返回0或1;
      时间复杂度O(logn);
      6. size() 返回map中键值对的数量;时间复杂度O(1);
      7. clear() 清空map中的所有键值对;时间复杂度O(n);
      8. empty() 判断map是否为空;时间复杂度O(1);
      9. begin() 返回map中第一个键值对的迭代器O(1);
      注意 在进行去找操作([]操作符)的时候，一定要保证key存在，否则可能产生错误，一般判断键值对是否存在的方法如下:map<>

#### 排序：
1. 快速排序 
   时间复杂度为O(nlogn),一般在数据范围1e6以内使用快排,且元素的大小一般很大
   ```cpp
   sort(v.begin(),v.end());//vector中
   sort(a,a+n);//C数组中
   ```
2. 桶排序
   时间复杂度为O(n),当元素的大小比较小的时候使用,利用值域小的特点
   桶排序 必须有 桶编号
   ```cpp
   int a[N];
   for(auto x:arr){
        a[x]++;
   }
   for(int i=1;i<=n;i++){
        for(int j=1;j<=a[i];j++){
            cout<<i<<" ";
        }
   }
   ```

#### 二分模板
整数二分
```cpp
bool check(int x) {/* ... */} // 检查x是否满足某种性质
 
// 区间[l, r]被划分成[l, mid]和[mid + 1, r]时使用：
int bsearch_1(int l, int r)
{
    while (l < r)
    {
        int mid = l + r >> 1;
        if (check(mid)) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}
// 区间[l, r]被划分成[l, mid - 1]和[mid, r]时使用：
int bsearch_2(int l, int r)
{
    while (l < r)
    {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
```
浮点数二分
```cpp
const double eps=1e-6;	// eps 表示精度，取决于题目对精度的要求

double bsearch_3(double l,double r)
{
	while (r-l>eps)
	{
		double mid = (l + r) / 2;//注意double类型不能用右移运算
		if (check(mid))  r = mid;
		else l = mid;
	}
	return l;
}
```

#### 高精度算法
高精度加法
```cpp
// 注意 A 和 B 是将两个数的每一位倒着放进了vector里面；
// C = A + B, A >= 0, B >= 0,也就是说A的长度要大于B；
vector<int> add(vector<int> &A, vector<int> &B)
{
    if (A.size() < B.size()) return add(B, A);
 
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size(); i ++ )
    {
        t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
 
    if (t) C.push_back(t);
    return C;
}
```
高精度减法
```cpp
// 注意 A 和 B 是将两个数的每一位倒着放进了vector里面；
// C = A - B, 满足A >= B, A >= 0, B >= 0
vector<int> sub(vector<int> &A, vector<int> &B)
{
    vector<int> C;
    for (int i = 0, t = 0; i < A.size(); i ++ )
    {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);
        if (t < 0) t = 1;
        else t = 0;
    }
 
    while (C.size() > 1 && C.back() == 0) C.pop_back();//消除前导零
    return C;
}
```
高精度乘低精度
```cpp
// 注意 A 和 B 是将两个数的每一位倒着放进了vector里面；
// C = A * b, A >= 0, b > 0
vector<int> mul(vector<int> &A, int b)
{
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size() || t; i ++ )
    {
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }
 
    return C;
}
```
高精度除以低精度
```cpp
//注意vector A，B是将每个数的每一位倒着存储在A，B里面了
// A / b = C ... r, A >= 0, b > 0
vector<int> div(vector<int> &A, int b, int &r)
{
    vector<int> C;
    r = 0;
    for (int i = A.size() - 1; i >= 0; i -- )
    {
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end());
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```
